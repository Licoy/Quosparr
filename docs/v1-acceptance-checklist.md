# v1 隔离安装与升级验收清单

v1 已正式发布（`v1.0.0`、`v1.0.1`），Swift 主应用与应急回滚已从仓库移除；本清单用于后续版本公开发布前的隔离验收，Swift 历史版本只作为升级来源

2026-10-13 自动验证记录：完整 Go race、发布辅助回归及工作流静态检查通过，Windows / Linux 的 amd64、arm64 开发安装包已生成并通过载荷校验；未使用 Docker；新增 Actions 原生回归、安装 / 卸载与 SQLite 执行步骤尚待上传代码后实际运行，以下桌面及升级验收状态保持不变

状态：填写清单、源码检查、模拟测试或交叉编译都不等于验收通过

本清单对应 v1 总计划第五节，所有行初始均为「未执行」；仅实际执行并留存脱敏证据后可改为「通过」，不能将未知状态记为通过，任何必需项失败都阻止公开发布

```bash
go build ./...
go vet ./...
go test -count=1 ./...
go test -race -count=1 ./internal/...
GOOS=darwin GOARCH=arm64 go build ./...
GOOS=darwin GOARCH=amd64 go build ./...

GOOS=windows GOARCH=arm64 go build ./...
GOOS=linux GOARCH=amd64 go build ./...
GOOS=linux GOARCH=arm64 go build ./...
bash Scripts/verify-v1-release.sh "$DIST" "$CONFIG"
```
