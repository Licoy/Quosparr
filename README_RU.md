# Quosparr

<sub><i>Название — из <b>Quo</b>ta (квота) + <b>Sparr</b>ow (воробей)</i></sub>

Маленький воробей в строке меню, который присматривает за квотами Codex, Claude, Gemini и Grok.

Quosparr — нативное приложение для строки меню / системного трея на macOS, Windows и Linux. Оно показывает квоты Codex, подписки Claude Code, Gemini (Google Antigravity) и Grok, reset credits, эквивалентную стоимость API и локальные сессии, а также отдельное управление аккаунтами для каждого провайдера. Глобальными навыками, серверами MCP и локальными сессиями всех четырёх провайдеров можно управлять в одном месте.

</div>

## Возможности

**Codex**

- Оставшаяся квота для 5-часового, недельного и дополнительных окон, а также текущий аккаунт, уровень подписки и срок действия.
- Число кредитов сброса, статус и время истечения.
- Оценка недельного лимита по официальному недельному проценту и дневным Credits с сравнением с прошлыми неделями, чтобы заметить урезание квоты.
- Обновления сбросов Codex: сбросились ли сегодня лимиты Codex, с собственным интервалом обновления (данные с [Did Codex Reset](https://didcodexreset.com)).
- Аккаунты провайдеров: вход через браузер, импорт локального `auth.json`, вставка токена / JSON (включая `/auth/session`), импорт файлов или добавление API-ключа. Переключение после подтверждения атомарно записывает `~/.codex/auth.json`.
- API-аккаунты: Base URL и API-ключ (пустой Base URL — официальный API OpenAI), модель можно выбрать из списка, полученного с сайта. При переключении записываются `auth.json` и провайдер `quosparr` в `config.toml` (с резервной копией), а баланс релеев типа new-api или OpenAI-совместимых показывается в списке аккаунтов, панели, строке меню, плавающем окне и виджете. Вход по ключу, для которого `config.toml` уже выбирает релей, подхватывается с этим сайтом и моделью. При правке текущего аккаунта можно заменить ключ (пусто — оставить) и выбрать, переписать ли файлы настроек сразу; после этого перезапустите Codex.
- Недавние сессии, проекты и статус, а также восстановление локального индекса сессий.

**Claude**

- Использование подписки Claude Code: 5-часовое окно, 7-дневное окно, недельные окна по моделям и дополнительное использование. Это чтение не является документированным публичным API биллинга.
- Локальные логи сессий Claude Code дают использование токенов, эквивалентную стоимость API (`anthropic-builtin-2026-10-14`), недавние сессии и скорость вывода. Один ответ считается один раз. Неизвестным моделям не назначается точная стоимость. В логах нет времени до первого токена, поэтому в этой колонке «—», а скорость считается по времени от начала до конца.
- Аккаунты подписки: вход через браузер без предварительного запуска CLI, импорт текущего входа, вставка учётных данных или импорт файла. Вход через браузер поддерживает отмену и вставку обратного вызова, добавляет аккаунт только в библиотеку; для использования в Claude Code нужно явно переключиться. Quosparr не обновляет текущий аккаунт; если вход истёк, один раз запустите `claude`. Остальные управляемые аккаунты обновляются только в своих копиях библиотеки.
- На macOS официальные учётные данные остаются в Связке ключей и читаются и записываются через `/usr/bin/security`. В Windows и Linux это `<config>/.credentials.json`. Переключение заменяет только `claudeAiOauth`, сохраняет токены MCP и обновляет только `oauthAccount` в `.claude.json`. Работающий процесс Claude Code не завершается и может записать прежний вход обратно, поэтому перед переключением показывается предупреждение.
- API-аккаунты: Base URL и API-ключ, с необязательным сопоставлением моделей Opus / Sonnet / Haiku / Fable из списка сайта. При переключении в `settings.json` записываются только `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN` и сопоставление (с резервной копией), вход по подписке не меняется; при возврате к подписке эти ключи удаляются. Баланс релея показывается везде, где показана квота Claude. Релей, уже прописанный в `settings.json`, импортируется автоматически. При правке текущего аккаунта можно заменить ключ (пусто — оставить) и выбрать, переписать ли `settings.json` сразу; после этого перезапустите Claude Code.

- **Подписки Claude Desktop**: привяжите аккаунт из любого списка, вручную войдите в показанный аккаунт и организацию и подтвердите это в Quosparr. Каждая операция просит сохранить задачи и согласиться завершить Desktop и сохранить/восстановить всю локальную конфигурацию, включая вход, настройки и состояние. Завершение или отмена привязки возвращает предыдущую конфигурацию. Связанное переключение по умолчанию выключено; текущий аккаунт CLI может открыть привязанный Desktop отдельно. Результаты CLI и Desktop показаны раздельно; запуск не подтверждает личность.
- Профили и зашифрованные самим Desktop данные входа приватно хранятся в `~/.quosparr/claude-desktop` (в Windows — protected ACL только текущего пользователя), сохраняют штатный путь данных и не расшифровываются или экспортируются вместе с аккаунтами. Исходная конфигурация сохраняется отдельно без импорта её аккаунта; данные браузеров и других приложений не читаются. Профили и данные Desktop должны быть на одном томе; после прерывания доступно явное восстановление. Аккаунты API исключены. Проверка реальных устройств и совместимости версий Desktop на macOS, Windows и Linux ещё не завершена.

**Gemini**

- Квоты клиентов Google Antigravity (нового настольного App и CLI `agy`): остаток и время сброса 5-часового и недельного окон для моделей Gemini и для моделей Claude, недельного окна Argon, а также тариф (Free / Pro / Ultra) и квоты по моделям. Эти данные берутся из службы Cloud Code, которой пользуются клиенты, и не являются документированным публичным API биллинга.
- Аккаунты: вход в Google через браузер, импорт текущего входа, вставка JSON учётных данных или импорт файла аккаунтов; текущий вход добавляется автоматически, поддерживаются псевдонимы, порядок, экспорт и обновление неактивных аккаунтов. Вход через браузер только добавляет аккаунт в библиотеку (кроме первого аккаунта, когда библиотека пуста и входа ещё нет). После подтверждения переключение записывает общий для App и `agy` вход в системное хранилище учётных данных; на macOS запущенный настольный App Antigravity можно перезапустить при переключении, а в Windows и Linux, как и запущенный `agy`, клиент нужно перезапустить самостоятельно.
- Локальные сессии App и `agy`: использование токенов, эквивалентная стоимость API, тепловая карта, последние сессии и анализ скорости. Стоимость оценивается по ценам models.dev: тарифы Google для моделей Gemini и тарифы Anthropic для моделей Claude в Antigravity; встроенной таблицы цен нет, поэтому стоимость появляется после синхронизации каталога цен, а неизвестным моделям точная стоимость не назначается.

**Grok**

- Включённая квота, разбивка Build / Imagine / Chat, недельные / месячные периоды, предоплаченный баланс и использование по требованию через официальный CLI chat-proxy billing API.
- Несколько аккаунтов OAuth / SuperGrok: изолированный вход, импорт текущего входа, вставка учётных данных, обновление, псевдонимы, порядок и явное переключение.
- Недавние сессии из локальных логов Grok CLI.

**Все провайдеры**

- Раздел «Цены моделей» находится перед «Дополнительно» в той же группе; публичный каталог models.dev автоматически обновляется каждый час по умолчанию, автообновление можно отключить, выбрать готовый или свой интервал от 15 минут до 7 дней; изменения сохраняются сразу, ручное обновление доступно и без автоматического
- Цены моделей — справочные ставки в USD за миллион токенов, без всех тарифов изображений, видео и других модальностей; справочная и применённая цены могут различаться ради сохранения проверенных уровней контекста, TTL записи кеша, Fast и региональных правил; в деталях указаны источник и версия, а встроенные таблицы с датами ниже остаются офлайн-базой；Только OpenAI, Anthropic, Google и xAI под исходными идентификаторами и их встроенные цены показаны на фиксированных вкладках Codex / Claude / Gemini / Grok, начиная с Codex, без других провайдеров; сторонние посредники и одноимённые модели других провайдеров исключены, models.dev — агрегированный публичный каталог, а не официальный интерфейс провайдеров в реальном времени；Кнопка настроек рядом с вкладками открывает системный диалог, где автосинхронизация, интервал и подробный статус общие для всех провайдеров и сохраняются сразу; закрытие диалога не отменяет синхронизацию; у Google нет встроенной таблицы, поэтому вкладка Gemini и стоимость сессий Gemini зависят от синхронизированного каталога, а модели Claude в Antigravity используют записи Anthropic
- Эквивалентная стоимость API пересчитывает прошлое локальное использование по текущим ценам; частичная стоимость отмечается для итога, дней, проектов, моделей и сессий с полным списком отсутствующих ставок или правил; — означает отсутствие цены, $0 — явно бесплатную цену, значения квот подписки и reset credits не меняются
- Синхронизация цен скачивает только публичный каталог через сохранённые настройки прокси, не отправляя логи сессий; офлайн используются встроенные цены и последний успешно сохранённый каталог, ошибки синхронизации остаются видимыми
- Всегда видимые вкладки `Codex | Claude | Gemini | Grok`. На macOS в настройках «Значок в строке меню» можно посмотреть пять стилей: полосы квоты, обратный отсчёт, батарея (горизонтально или вертикально), кольца квоты (значения можно показывать внутри колец) и текст прогресса. Строка меню следует панели или показывает любых из четырёх провайдеров, каждого отдельно; полосы, отсчёт и батарея могут также ставить двух провайдеров друг над другом в одном элементе. Уже сохранённая пара «Codex + Grok» остаётся этой парой.
- Необязательное плавающее окно поверх всех окон показывает остаток квоты до четырёх провайдеров в четырёх стилях: капсула, карточка, кольца или батарея. Щелчок открывает панель, перетаскивание перемещает окно, правый щелчок открывает другие параметры. Можно настроить непрозрачность, закрепление позиции и показ поверх полноэкранных приложений.
- Эквивалентная стоимость API и использование токенов за сегодня, текущий цикл, предыдущий цикл, этот месяц или свой диапазон.
- График использования токенов с начала года в виде теплокарты, линии или столбцов (по дням / неделям / накопительно).
- Страница Skills показывает глобальные навыки каждого поставщика: откуда навык, загружает ли его CLI и какие ещё CLI его читают; поиск, просмотр `SKILL.md`, открытие папки, включение и отключение в собственной конфигурации CLI (с резервной копией), копирование или перемещение в другой CLI (навык с тем же именем не перезаписывается), перемещение в корзину навыков Quosparr и диагностика битых ссылок, вложенных папок и повторяющихся имён; большинство проблем исправляется в один клик, несколько навыков можно выбрать и удалить или исправить вместе, а риски всегда показываются до подтверждения. В «Настройки › Навыки» есть вкладка для каждого поставщика с фильтрами по состоянию и типу, страница навыка (источник установки, файлы, frontmatter, ссылки на репозиторий GitHub или домашнюю страницу) и корзина, из которой навык можно восстановить или отправить в системную корзину. В «Настройки › Навыки» можно также добавить навыки из публичного репозитория GitHub (ссылка или `owner/repo`), локальной папки или zip: Quosparr находит папки навыков на любой глубине, не берёт файлы систем контроля версий, результаты сборки и системные файлы, позволяет выбрать навыки и целевые CLI (или общую папку `~/.agents/skills`) и никогда не перезаписывает папку с тем же именем. Для навыков из GitHub запоминается источник и доступна проверка обновлений; обновление заменяет папку последней версией из репозитория, а старая версия уходит в корзину навыков. Навыки Gemini берутся из `~/.gemini/config/skills` и других пользовательских папок навыков App Antigravity и `agy`, а также из их встроенных навыков и навыков плагинов; в Antigravity нет переключателя для отдельного навыка, поэтому навыки Gemini показывают состояние без переключателя, а пользовательские навыки можно переместить в корзину навыков или скопировать и переместить в другой CLI.
- В «Настройки › Сеансы» перечислены все локальные сессии каждого поставщика. Есть поиск по названию, проекту или ID, фильтры по проекту и диапазону дат, а на странице сессии видны модель, разбивка токенов, эквивалентная стоимость API, файлы и предпросмотр диалога. Выбранные сессии после подтверждения по одной перемещаются в системную корзину и не удаляются безвозвратно; официальные индексы и базы данных не меняются, а производная статистика пересчитывается по оставшимся журналам. Исключение — Gemini: его сессии можно удалить, только когда App Antigravity и `agy` не запущены; Quosparr сначала делает резервную копию базы индекса сессий, перемещает файлы сессий в системную корзину и затем удаляет их записи из этого индекса; страницы подробностей для сессий Gemini пока нет.
- В «Настройки › MCP» перечислены глобальные пользовательские серверы MCP каждого поставщика (`config.toml` у Codex и Grok, `.claude.json` у Claude, общий для App Antigravity и `agy` файл `~/.gemini/config/mcp_config.json` у Gemini). Команда, сайт и структура показываются только в виде сводки без секретов, значения env и headers не выводятся, а Quosparr не подключается к серверам и не запускает их, если только вы не запросите предпросмотр инструментов при добавлении. Серверы можно добавить в один или несколько CLI через форму или вставленный JSON; серверы с уже существующими именами не меняются, а Gemini принимает только серверы stdio и HTTP. Выбранные записи можно удалить вместе: перед добавлением или удалением файл копируется в `~/.quosparr/backups`, остальные настройки сохраняются, а изменение вступает в силу после перезапуска CLI. У серверов Codex, Gemini и Grok есть также переключатель включения, который сохраняется после той же резервной копии: Codex записывает `enabled` у записи, Gemini — `disabled` у записи, а Grok, как и его собственный CLI, также обновляет `disabled_mcp_servers`. Claude Code хранит включение MCP для каждого проекта, поэтому у серверов Claude переключателя нет. Серверы MCP уровня проекта, плагинов и корпоративного управления не показываются.
- Светлое, тёмное и системное оформление; English, 简体中文, 繁體中文, 한국어, 日本語, Русский, Français.
- Встроенные обновления и виджеты рабочего стола на macOS 14+.

## Установка

Скачивайте из [GitHub Releases](https://github.com/Licoy/Quosparr/releases) и выбирайте пакет под свою систему и процессор:

| Система | Пакет | Как установить |
| --- | --- | --- |
| macOS 12+ (Apple Silicon / Intel) | `Quosparr-macos-arm64.dmg` / `Quosparr-macos-x86_64.dmg` или `.zip` с тем же именем | Перетащите `Quosparr.app` в `Applications` |
| Windows 10 / 11 (amd64 / arm64) | `Quosparr.Setup.<version>.<arch>.exe` | Установка для текущего пользователя в `%LOCALAPPDATA%\Programs\Quosparr`; права администратора не нужны |
| Linux (amd64 / arm64) | `quosparr-<version>-linux-<arch>.tar.gz` с `install.sh` или `quosparr_<version>_<arch>.deb` | Выполните `sh install.sh` рядом с архивом, чтобы установить в `~/.local`, либо установите deb через менеджер пакетов |

Каждый пакет содержит среду выполнения SQLite для своей архитектуры, поэтому при первом запуске ничего не скачивается. При первом запуске Quosparr по умолчанию включает запуск при входе; изменить это можно в **Панель управления → Основные → Запуск при входе**.

Установка через Homebrew пока недоступна; используйте DMG или ZIP.

Если вы раньше пользовались CodexRunway, см. [руководство по переходу](docs/upgrade-from-codexrunway_RU.md).

### Требования для Linux

Для Linux нужны GTK3, AppIndicator, рабочий стол с поддержкой трея и работающий сеанс Secret Service (например, GNOME Keyring или KWallet) для хранения учётных данных прокси. Пакет deb объявляет эти зависимости и обновляется через менеджер пакетов.

## Требования

- Рекомендуется, чтобы Codex был установлен и использовался на этом компьютере. Данные Codex берутся из `CODEX_HOME` (по умолчанию `~/.codex`, а в Windows `%USERPROFILE%\.codex`).
- Поддерживается только хранилище учётных данных `file` (значение по умолчанию, если `cli_auth_credentials_store` не задан в `config.toml` Codex). `keyring`, `auto` и `ephemeral` помечаются как неподдерживаемые и блокируют импорт и переключение аккаунтов.
- Панель Claude читает настройки Claude Code из `CLAUDE_CONFIG_DIR`, если задан, иначе из `~/.claude`. Для использования подписки нужен вход Claude.ai; API-ключ или шлюз его не дают. Вход через браузер не требует установки или предварительного запуска CLI и сохраняется только в библиотеке до явного переключения. Существующие входы CLI добавляются автоматически; можно также вставить JSON учётных данных или импортировать файл. Реальную авторизацию в браузере и переключение ещё нужно проверить на изолированном аккаунте.
- Для панели Gemini нужно установить новый настольный App Google Antigravity или CLI `agy` и войти в аккаунт; оба используют один и тот же вход в системном хранилище учётных данных (Связка ключей macOS, Диспетчер учётных данных Windows или Linux Secret Service). Antigravity до версии 2.0 и Gemini CLI не поддерживаются. Локальные данные читаются из `~/.gemini`. Текущий вход добавляется автоматически; вход через браузер в Quosparr сохраняется только в библиотеке до явного переключения. Реальную авторизацию в браузере, переключение и перезапуск клиентов ещё нужно проверить на изолированном аккаунте.
- Для панели Grok нужен [официальный Grok CLI](https://docs.x.ai/build/overview):

  ```bash
  curl -fsSL https://x.ai/cli/install.sh | bash
  ```

- Аккаунты и квоты Grok поддерживают только OAuth / SuperGrok и совместимые legacy-сессии. Выполните `grok login --oauth`, войдите из приложения, импортируйте текущий вход или вставьте JSON учётных данных. Входы только по API-ключу не добавляются как управляемые аккаунты. Если задан `GROK_HOME`, используется он, иначе `~/.grok`.

## Виджеты рабочего стола

Виджеты требуют macOS 14 или новее; в Windows и Linux их нет. Доступны четыре типа виджетов: обзор квоты, тренд токенов, ключевой показатель и обновления сбросов Codex. Для каждого виджета в «Править виджет» можно выбрать Codex, Claude, Gemini, Grok или пару: Codex + Claude, Codex + Gemini, Codex + Grok, Claude + Gemini, Gemini + Grok, Grok + Claude. Виджет, уже поставленный на Codex + Grok, сохраняет эту пару. Нажатие открывает соответствующую страницу.

Снимок хранится в `~/.quosparr/widget-snapshot.json` с правами `0600` и содержит только несекретные производные данные: без почты, ID аккаунта, токена, auth JSON и исходного текста событий. Единственный писатель — главное приложение; виджеты только читают.

## Сетевой прокси

В разделе **Панель управления → Основные → Сеть** выберите **Системные настройки**, HTTP или SOCKS5; для собственных прокси поддерживаются имя пользователя и пароль. Настройка действует на запросы Codex, Claude, Gemini и Grok, запускаемые приложением, операции CLI, открытые источники статуса и цен, а также обновления программы. Системный прокси не изменяется, а страницы входа в браузере и уже запущенные внешние CLI сохраняют свои настройки.

Изменения применяются только после **Сохранить настройки прокси**. **Проверить соединение** открывает тестовый сайт (по умолчанию `https://github.com`, можно изменить) с текущим черновиком настроек, не отправляя учётные данные аккаунта и не сохраняя черновик. Пароли прокси хранятся в Связке ключей macOS, Диспетчере учётных данных Windows или Linux Secret Service. Неверные настройки, недоступные учётные данные или сбой собственного прокси никогда не приводят к переходу на прямое соединение.

## Конфиденциальность

- Quosparr хранит собственные данные в `~/.quosparr` и не пишет кэш приложения в `~/.codex`. По умолчанию сохраняются только несекретные производные данные.
- Контролируемые исключения — учётные данные аккаунтов и явно подтверждённые профили Desktop, описанные выше; учётные данные они хранятся в `~/.quosparr/accounts/<id>/auth.json` (каталог `0700`, файл `0600`, атомарная запись; в Windows используется ACL, доступный только текущему пользователю). Индекс аккаунтов не содержит токенов.
- Официальный `~/.codex/auth.json` записывается только при обновлении OAuth или когда вы подтверждаете переключение аккаунта. Обновление нетекущего аккаунта изменяет только его копию в библиотеке.
- Учётные данные Claude на macOS читаются из Связки ключей через `/usr/bin/security`, а в Windows и Linux из `<config>/.credentials.json`. Управляемые копии лежат в `~/.quosparr/accounts/claude-<stable-id>/auth.json` и содержат только `claudeAiOauth`. Индекс `claude-index.json` не содержит токенов. Переключение сохраняет токены MCP и заменяет только `oauthAccount` в `.claude.json`. Quosparr не обновляет текущий аккаунт.
- Ключи API-аккаунтов хранятся только в управляемой копии (`~/.quosparr/accounts/<id>/auth.json` или `claude-api-<id>/auth.json`); индексы содержат только Base URL, модели и кэш баланса. Запросы баланса и моделей идут только на указанный сайт с учётом настроек прокси. Изменяемые `config.toml` и `settings.json` сначала копируются в `~/.quosparr/backups`; при первой записи `settings.json` ключи сортируются.
- Учётные данные Gemini читаются из общей для клиентов Antigravity записи системного хранилища учётных данных (на macOS через `/usr/bin/security`, секреты передаются только через стандартный ввод), а при её отсутствии — из `~/.gemini/jetski-standalone-oauth-token` или `~/.gemini/antigravity-cli/antigravity-oauth-token`. Управляемые копии лежат в `~/.quosparr/accounts/gemini-<stable-id>/credential.json`; индекс `gemini-index.json` не содержит токенов. Официальный вход записывается только при переключении, при добавлении первого аккаунта в пустую библиотеку и при обновлении токена текущего аккаунта: записываются системное хранилище и только уже существующие зеркальные файлы, каждый перечитывается для проверки, а при ошибке восстанавливается прежний вход. Переключение при запущенных Antigravity или `agy` требует подтверждения.
- Учётные данные Grok читаются из `$GROK_HOME/auth.json`; управляемые копии лежат в `~/.quosparr/accounts/grok-<stable-id>/auth.json`. Переключение Grok заменяет только области OAuth / совместимого legacy-входа и сохраняет API-ключ и неизвестные области. Оно гарантировано только для новых сессий; запущенные процессы Grok не завершаются и могут записать предыдущий аккаунт обратно, поэтому приложение предупреждает перед переключением.
- Восстановление сессий затрагивает только `session_index.jsonl` и сначала создаёт его резервную копию. Журналы сессий перемещаются в системную корзину только после того, как вы выберете и подтвердите их в «Настройки › Сеансы»; перед перемещением каждый файл проверяется повторно, ничего не удаляется безвозвратно, а официальные индексы и базы данных не перезаписываются. Исключение — Gemini: перед удалением его сессий изменяемые базы индекса сессий копируются, а удаляются только записи сессий, все файлы которых перемещены; в остальных случаях эти базы читаются только из закрытых временных копий.
- Включение, исправление и удаление навыков и серверов MCP выполняются только после вашего подтверждения. Файлы конфигурации перед записью копируются в `~/.quosparr/backups`, удалённые навыки сначала попадают в восстанавливаемую корзину навыков Quosparr, а список MCP не показывает ключи и значения env и headers.
- При добавлении навыка сначала просматривается список файлов источника, и до любой записи в память читаются только папки навыков, поэтому большой репозиторий стоит лишь времени загрузки, а не памяти; скрипты навыков никогда не запускаются; источники GitHub загружаются только с GitHub по HTTPS с учётом настроек прокси. Откуда взят каждый добавленный навык (репозиторий, ref, коммит, папка в репозитории или локальный путь), хранится в `~/.quosparr/skill-sources.json` (`0600`) без каких-либо секретов.
- Эквивалентная стоимость API считается по локальным журналам сессий. Содержимое сессий не загружается.
- Токены и API-ключи никогда не записываются в журналы, вывод самопроверки и шаблоны issues.
- «Обновления сбросов Codex» и проверка обновлений получают только публичные данные; аккаунт, токены и содержимое сессий не отправляются.

## Источники данных

- **Квота Codex / reset credits / официальное использование**: официальные backend API ChatGPT / Codex с вашими локальными учётными данными. Официальное использование относится к текущему аккаунту и может запаздывать или пересматриваться.
- **Оценка недельной квоты**: неофициальная, экстраполируется из недельного процента и дневных Credits (1000 Credits ≈ $40, версия `credits-usd-2026-08-26`). В `quota-estimate-history.json` сохраняются только производные Credits и проценты.
- **Эквивалентная стоимость API Codex**: локальные журналы сессий, оценённые по встроенному прайсу `openai-builtin-2026-09-27`; поддерживаемые текущие ставки берутся из models.dev с сохранением проверенных встроенных правил. Неизвестные модели не выдаются как точная стоимость.
- **Использование подписки Claude Code**: недокументированная конечная точка OAuth usage. Она относится только к текущей подписке Claude Code и не называется официальным API биллинга. Cookie браузера и счёт Console API не читаются; профилями Desktop управляет только отдельная функция с явным подтверждением, описанная выше.
- **Эквивалентная стоимость API Claude**: локальные журналы сессий Claude Code и таблица `anthropic-builtin-2026-10-14`. Один ответ считается один раз по идентификатору сообщения. Запись в кэш делится на 5 минут и 1 час, тариф Fast считается отдельно. Неизвестным моделям не назначается точная стоимость. Сутки считаются в местном часовом поясе.
- **Квота Gemini**: недокументированные конечные точки Cloud Code, которыми пользуются клиенты Antigravity (`cloudcode-pa.googleapis.com` / `daily-cloudcode-pa.googleapis.com`); токены обновляются через Google OAuth (`oauth2.googleapis.com`), а аккаунт определяется по ID-токену или Google userinfo. Это не называется официальным API биллинга. Тариф берётся из платного уровня, иначе из текущего. Если Google требует подтверждения или подписки, сохраняется предыдущее значение.
- **Эквивалентная стоимость API Gemini**: использование токенов из локальных баз разговоров App (`~/.gemini/antigravity`) и `agy` (`~/.gemini/antigravity-cli`), всегда читаемых из закрытых временных копий; цены берутся только из синхронизированного каталога models.dev (тарифы Google для моделей Gemini, тарифы Anthropic для моделей Claude). Записи в кэш Anthropic и неизвестные модели не получают точной стоимости. Зашифрованные разговоры считаются нечитаемыми.
- **Квота Grok**: только официальная конечная точка CLI chat-proxy `/v1/billing?format=credits`. Без cookie браузера, без квоты, выведенной из локальных журналов, и без примеси API-биллинга.
- **Эквивалентная стоимость API Grok**: локальное использование `turn_completed`, оценённое по `xai-builtin-2026-09-27`, с учётом тарифов на ввод, кэш, вывод и длинный контекст. `costUsdTicks` — это учёт подписки, он не используется как эквивалент стоимости API.
- **Обновления сбросов Codex**: публичная лента [didcodexreset.com/api/status.json](https://didcodexreset.com/api/status.json). Неофициально, только для справки, возможны задержки.
- На графике «Официальная статистика (все устройства)» относится к текущему аккаунту, а «Локальные журналы (все сессии)» сканирует этот компьютер и может охватывать несколько аккаунтов. Они не являются подмножествами друг друга, их не следует вычитать; дневные значения Codex в обоих случаях используют сутки UTC.

## Разработка

Основное приложение написано на Go с нативным интерфейсом [mygo](https://github.com/egoist/mygo); версии Go и mygo зафиксированы в `go.mod`. Расширение виджета для macOS остаётся на Swift.

```bash
go test ./...
go vet ./...
go build ./...
```

Запускайте с временным HOME и отдельным доменом настроек, чтобы не затронуть реальные аккаунты и настройки:

```bash
QUOSPARR_TEST_HOME="$(mktemp -d)"
HOME="$QUOSPARR_TEST_HOME" QUOSPARR_PREFS_DOMAIN=com.quosparr.app.v1-test go run .
HOME="$QUOSPARR_TEST_HOME" QUOSPARR_PREFS_DOMAIN=com.quosparr.app.v1-test go run . --self-check
```

Самопроверка не делает сетевых запросов и не читает учётные данные. Сейчас она охватывает версию, платформу, права на собственные каталоги, блокировки и наличие Codex auth и индекса сессий; остальные проверки помечены как `not ported yet`.

Сборка пакета разработки для macOS (обновления отключены; при желании `ARCH=arm64` или `ARCH=x86_64`):

```bash
V1_DEVELOPMENT_PACKAGE=1 bash Scripts/package-v1-app.sh
```

Упаковка для Windows / Linux и проверки выпуска описаны в [docs/v1-release.md](docs/v1-release.md), заметки по вкладу — в [CONTRIBUTORS.md](CONTRIBUTORS.md).
